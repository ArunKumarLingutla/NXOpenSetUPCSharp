## Use this as template to start and rename as mentioned below
1. Create new repository and select this repo as template
2. Clone the New Repo to local
3. Rename .sln and .csproj files in SourceCode folder
4. After renaming files, update content inside
   - **open .sln file in NotePad:** Replace all project file names referenced (Not the .cs files) and save .sln file. (NXOpenSetUPCSharp.csproj --> AssemblyPractice.csproj) And (NXOpenSetUPCSharp --> AssemblyPractice)
   - **open .csproj file in NotePad:** Change RootNamespace and AssemblyName and save it. (NXOpenSetUPCSharp --> AssemblyPractice)
   - **Open solution in Visual Studio:** Open solution and and rename(Ctrl+R+R) the class and Name Space
